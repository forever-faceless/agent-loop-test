Reqio agent loop sandbox

A throwaway page whose only job is to host the Reqio widget, so a bug report can enter the loop the way a real visitor would file it.

What happens after you file one

  1. The report lands in the Reqio dashboard as a bug.
  2. A human moves it to In progress. That move is the approval.
  3. The scheduled workflow picks it up and opens a pull request on forever-faceless/agent-loop-test.
  4. Merging that pull request marks the request complete and notifies the reporter.
